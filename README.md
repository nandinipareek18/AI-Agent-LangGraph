# 🤖 AI Agent using LangGraph

A Streamlit-based AI Agent built using LangGraph, Groq, Tavily and Python.

## Features

- 🤖 Groq LLM
- 🧠 LangGraph ReAct Agent
- 🔎 Optional Tavily Web Search
- 🖥️ Streamlit Interface
- ⚙️ Custom System Prompt
- 🔐 Environment-based API keys

## Tech Stack

- Python
- Streamlit
- LangChain
- LangGraph
- Groq
- Tavily
